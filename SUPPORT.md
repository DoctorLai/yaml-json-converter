# Support

Thanks for using **YAML ↔ JSON Converter**! Here is how to get help.

## 📖 Documentation

- [README](./README.md) — features, installation, and usage.
- [CONTRIBUTING](./CONTRIBUTING.md) — local setup and development workflow.
- [AI-generated wiki](https://deepwiki.com/DoctorLai/yaml-json-converter) — a
  deeper, auto-generated tour of the codebase.

## 💬 Questions & Ideas

- Browse [existing issues](https://github.com/DoctorLai/yaml-json-converter/issues)
  to see if your question has already been answered.
- Open a new issue using the appropriate template for bugs or feature requests.

## 🐛 Reporting a Bug

Please open a
[bug report](https://github.com/DoctorLai/yaml-json-converter/issues/new/choose)
and include:

- What you did and what you expected to happen.
- What actually happened (error messages, screenshots).
- Your browser and operating system.
- A minimal YAML/JSON sample that reproduces the problem, if relevant.

## 🔐 Security Issues

Please **do not** file security problems as public issues. Follow the process in
[SECURITY.md](./SECURITY.md) instead.

## ❤️ Supporting the Project

If this tool saves you time, consider
[buying the maintainer a coffee](https://buymeacoffee.com/y0btg5r) ☕ or starring
the repository on GitHub.
